# Glossary

**accepted_hits.bam** — TopHat's main alignment file; input for Cufflinks and counting (Ch 3, 4)
**align_summary.txt** — TopHat report of mapped and multi-mapped reads (Ch 3)
**BAM** — compressed binary SAM; handled with samtools (Ch 3)
**BLAST database** — FASTA formatted by `makeblastdb` for fast searching (Ch 1)
**blastp** — protein query vs protein database search (Ch 1)
**Bowtie** — ultrafast short-read aligner, Burrows–Wheeler based (Ch 2)
**Bowtie2** — successor used internally by TopHat; index via `bowtie2-build` (Ch 3)
**Burrows–Wheeler index** — compressed genome index keeping aligner memory small (~2.2 GB human) (Ch 2)
**.chip** — GSEA chip annotation mapping probe IDs to HUGO symbols (Ch 6)
**.cls** — GSEA phenotype labels file (Ch 6)
**Collapse dataset to gene symbols** — GSEA option merging probe sets per gene (Ch 6)
**countdata** — count-only matrix with Entrez IDs as rownames (Ch 5)
**CPM** — counts per million; library-size-normalised count (Ch 5)
**Cufflinks** — transcript assembler/quantifier producing GTF + FPKM (Ch 4)
**Edit distance** — mismatches + insertions + deletions between read and reference (Ch 3)
**edgeR** — Bioconductor package; `cpm()` used for filtering (Ch 5)
**E-value** — expected chance hits; lower = more significant (`-evalue 1e-6`) (Ch 1)
**.faa** — FASTA amino-acid file (Ch 1)
**FASTQ (.fq)** — read sequences with base qualities (Ch 2, 3)
**featureCounts** — read-counting tool used to create GSE60450 counts (Ch 5)
**FDR** — false discovery rate; GSEA leading-edge demo uses FDR < 0.01 (Ch 5, 6)
**FPKM** — fragments per kilobase per million mapped reads (Ch 4)
**.gct** — GSEA expression dataset format (Ch 6)
**.gmt** — GSEA gene sets file (Ch 6)
**GSE60450** — GEO accession, mouse mammary gland basal/luminal study (Ch 5)
**GSEA** — Gene Set Enrichment Analysis, Broad Institute (Ch 6)
**GTF** — gene transfer format; `transcripts.gtf` from Cufflinks (Ch 4)
**Index basename** — shared prefix of index files passed to aligner (Ch 2, 3)
**junctions.bed** — TopHat intron coordinates (Ch 3)
**Leading edge subset** — genes driving a set's enrichment score (Ch 6)
**makeblastdb** — builds BLAST database from FASTA (Ch 1)
**MSigDB** — Molecular Signatures Database of curated gene sets (Ch 6)
**Multi-mapped read** — read aligning to several loci; excluded with TopHat `-M` (Ch 3)
**Permutation (GSEA)** — phenotype-label shuffling for significance; 5 pilot, 1000 final (Ch 6)
**Pipe (`|`)** — passes one command's output to another (Ch 1)
**SAM** — text alignment format; Bowtie `-S` (Ch 2)
**samtools** — BAM/SAM sort, merge, view (Ch 3)
**Splice junction** — exon–exon boundary spanned by RNA-seq reads (Ch 3)
**TopHat** — spliced RNA-seq aligner built on Bowtie2 (Ch 3)
**UCSC custom track** — user-uploaded annotation in UCSC Genome Browser (Ch 4)
